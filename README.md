# video-check：ショート動画のかんたん診断（Web版）

縦のショート動画をブラウザで選ぶだけで、6つの項目を「伸びるショート動画の目安」と比べて、レーダーチャートと解説で見せる無料ツール。
**動画も結果もサーバーに送らず、保存もしない**（すべて端末のブラウザの中で計算する）。

## 何ができるか
| 項目 | 測り方 | 向き |
|---|---|---|
| 冒頭3秒の絵の動き | 0〜3秒を0.5秒ごとに取り出したコマ（横32px）の、となりどうしの色の差の平均（0〜100） | 中央に近いほど良い |
| 絵の切り替わり | となりのコマとの差が20を超えた回数を1分あたりに直す（回/分） | 中央に近いほど良い |
| 話す速さ（任意） | ボタンを押した人だけ。Whisper tiny で文字起こし → 文字数 ÷ 話している時間（0.3秒以上の間を除く）（文字/秒・目安） | 中央に近いほど良い |
| 音のない時間 | 音量 −40dB 以下が1秒以上続いた区間の合計 ÷ 動画の長さ（%） | 少ないほど良い |
| 動画の長さ | 動画の長さ（秒） | 中央に近いほど良い |
| 終わりと始まりのつながり（ループ） | 最初のコマと最後のコマの似ている度合い（100−色の差、%）。最後の0.5秒が無音かも出す | 多いほど良い |

### 点数の出し方（`js/score.js`）
- 基準の表の分布（下位10%・25%・中央・75%・90%）を使う
- 中央＝100点、25%・75%の線＝80点、10%・90%の線＝50点。その外は、中央〜10%（90%）と同じ距離だけ離れたところで0点。線のあいだは直線でつなぐ
- 「少ないほど良い」は中央より少なければ100点、「多いほど良い」は中央より多ければ100点
- 札：80点以上「目安どおり」／50〜79点「少しずれ」／50点未満「伸びしろあり」／測れないものは「未測定」

## 画面の流れ（v2：初心者向け・相手は「誰でも」）
1. はじめ：「伸びるショート動画は、どこが違う？」。「どんな動画を入れますか？」で **好きな動画（最初の選び方）／自分で作った動画** を選ぶ（押さなくてもよい）→「動画を選ぶ」
2. 調べている：進み具合・手順。「やめる」でもどれる
3. 結果：いちばん上に「大事な1点」（自分の動画＝まず直すところ1つ／好きな動画＝伸びる作りにいちばん近いところ1つ）→ すぐ下に注意1行 → 「〜として見る」で見方を切り替え（測り直さない）→ ほかの項目（押すと開く）→ 話す速さ（任意）→ 全体の形 → 次の行動
- 並び順・選び方は `js/key_point.js`・`js/item_order.js`（テスト `tests/key_point.test.js`・`tests/item_order.test.js`）
- スマホで待つ時間は、実機で測った値を `js/config.js` の `PHONE_WAIT_TEXT` に入れるまで画面に出さない（今は PC の「約1分」だけ）
- 画面に版番号・本数は出さない（`data/baseline.json` の項目は残してある）

## 使い方
- 公開版：GitHub Pages のページを開いて「動画を選ぶ」を押す（上限：3分・200MB。mp4（H.264）がいちばん確実）
- 手元で確かめるとき：ファイルを直接開く（file://）と JS が動かないので、このフォルダで小さなサーバーを立てる
  ```
  python -m http.server 8000
  ```
  → ブラウザで `http://localhost:8000/` を開く（手元では計測の通信は起きない）
- テスト：このフォルダで `node --test`（依存ライブラリなし。Node.js 20 以上）
- 機密チェック：`python ci/confidential_check.py`

## 基準の表 `data/baseline.json`
- 数字だけの表。差し替えるだけで点数と「基準の範囲」の表示が変わる（コードは変えない）
- 形：`version`・`created`・`count`（本数。実数が入るまで `null`＝画面は「○本」）・`source`（出所の一般的な説明）・`note`・`axes`（項目ごとに `unit`・`direction`（near／more／less）・`percentiles`（p10〜p90、小さい順））
- **今の数字は仮**。基準は、許可を取った動画を手元版で測った値と公開調査の目安から、別の手元スクリプトで作る（そのスクリプトと途中のデータはこのリポジトリに入れない）。スクレイピングはしない
- 個別の動画のID・URL・アカウント名・動画ファイルは入れない（テストで確かめている）
- 基準を作るときは、上の「測り方」と同じ定義で測った値を使う

## 通信と保存について
- 読み込むのは同じサイトのファイルだけ。外への通信は GoatCounter への「ページを開いた」記録1回だけ（1×1 の画像。送るのはページの場所と来たページのドメイン＋場所だけ。動画名・値・点数は送らない。手元で開いたとき・「追跡しない」設定のときは送らない）
- CSP（読み込み先の制限）は `index.html` の先頭。`'wasm-unsafe-eval'` は文字起こしの部品（WebAssembly）を動かすため
- localStorage・IndexedDB・Cookie は使わない。文字起こしのモデルだけはブラウザのキャッシュに残る（2回目から速くするため）
- 文字起こしのライブラリとモデルは外のサイト（CDN）からは読まず、`vendor/` に置いたものを、ボタンを押したときだけ読む

## 軽さ（AC-26〜30）
- 最初に開いたときに読む量：約160KB（圧縮前。HTML・CSS・JS・基準の表。画像・Webフォントなし）
- 「話す速さも測る」を押したあとだけ：約66MB（文字起こしの部品 約22MB＋モデル 約44MB）
- リポジトリ全体の大きさ：**約66MB**（ほぼ vendor/。100MB以下）。置くモデルは Whisper tiny の8bit版1つだけ

## ライセンス表示（画面の「くわしく知りたい人へ」の中にも表示）
- 文字起こしライブラリ：Transformers.js 3.8.1（Hugging Face、Apache-2.0）。中に ONNX Runtime Web（Microsoft、MIT）を含む
- 文字起こしモデル：Whisper tiny（OpenAI、Apache-2.0）。ONNX 形式・8bit 版は onnx-community が変換したもの

## 注意書き
- 基準は伸びるショート動画の目安です。近づけても再生が伸びることは約束できません
- 文字起こしは完全ではありません（軽いモデルのため、固有名詞・数字・漢字で誤りやすい）。話す速さは目安です
- このツールは動画の見た目と音の傾向を測るだけです。**投資の助言ではありません**
- 基準のジャンル（語り・料理・Vlog など）は分けていません
